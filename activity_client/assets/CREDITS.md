# Sprite credits

`sprite_male.png` and `sprite_female.png` are composited (body + head layers, "light" skin tone,
walk animation) from the [Universal LPC Spritesheet Character
Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/)
project, using assets from its
[GitHub repo](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator).

These are part of the Liberated Pixel Cup (LPC) art pack -- an open, collaboratively-built set of
game assets explicitly released for reuse in games. The body layer specifically is credited to
(per the upstream project's own credits data): bluecarrot16, JaidynReiman, Benjamin K. Smith
(BenCreating), Evert, Eliza Wyatt (ElizaWy), TheraHedwig, MuffinElZangano, Durrani, Johannes
Sjölund (wulax), and Stephen Challener (Redshrike), dual/multi-licensed under OGA-BY 3.0,
CC-BY-SA 3.0, and GPL 3.0. See the upstream repo's own `CREDITS.csv` and `LICENSE` for the
complete, authoritative attribution across every layer used by the generator.

These are the bare base body sprites deliberately, with no clothing/hair layered on -- intended
as a "mannequin" base to layer equipment sprites onto later.
